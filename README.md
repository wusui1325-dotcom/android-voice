# android-voice

即時 Android 變聲器，專注將輸入聲音轉為較自然的女聲。

## 目的

提供一個本地、免費、可調參數的即時變女聲方案，取代市面上品質不佳或廣告過多的免費 App。

## 理想效果

- 明顯女聲感
- 盡量保留原音色，避免花栗鼠或機器人感
- 即時延遲控制在可接受範圍（目標 150–250 ms）

## 應用場景

- 即時語音通話
- 直播或遊戲語音
- 語音訊息錄製

## 對象

需要即時變女聲功能的 Android 使用者，偏好本地處理、無伺服器依賴。

## 設備最低要求

- Android 8.0（API 26）或以上
- 支援低延遲音訊（AudioRecord / AudioTrack 或 AAudio）
- 建議使用有線耳機或藍牙耳機以降低回音
