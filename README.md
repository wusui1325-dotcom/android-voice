# android-voice

本地即時 Android 變聲器。將任意輸入聲音轉換為自然、可調的女聲，無需伺服器、無需上傳。

## 目的

讓任何 Android 裝置都能即時擁有高品質的變女聲能力。本地處理、完全可控、無廣告、無隱私顧慮。

## 理想效果

- 清晰可辨的女聲感，同時保留原說話者的語氣與個性
- 避免過度尖銳或機械感
- 即時延遲控制在可日常使用的範圍（目標 150–250 ms）

## 應用場景

- 即時語音通話與視訊會議
- 直播、遊戲語音與語音聊天
- 短影片、語音訊息與內容創作
- 語言練習、角色扮演與娛樂使用
- 需要臨時改變聲線的任何場合

## 對象

希望在 Android 上使用即時、本地、可調變女聲功能的使用者。

## 最低支援

- **系統**：Android 8.0（API 26）或以上
- **處理器**：64-bit ARM（ARMv8-A 或更新）
- **記憶體**：建議 2 GB 以上
- **音訊**：支援 AudioRecord / AudioTrack 或 AAudio 的裝置
- **建議**：使用有線或藍牙耳機以降低回音與延遲感知
